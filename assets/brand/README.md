# DPI Fix logo

Kullanıcının seçtiği Leonardo.AI görseli `dpifix-logo.png` olarak korundu.
Uygulama simgesi/başlık işareti ve yerel site logosu için siyah desenli arka plan temizlenmiş `dpifix-mark.png` kullanılır.

- `dpifix.ico`: Windows uygulama ve kurulum simgesi, 16–256 px boyutlar
- `dpifix-mark.png`: şeffaf arka planlı, kare PNG (GUI/site)
- `dpifix-logo.png`: sunulan orijinal görsel
- `dpifix-{256,128,64,48,32}.png`: küçük yüzeyler için küçültülmüş varyantlar

Renkler ve keskin kenarlar korunmuştur; yalnızca siyah desenli arka plan şeffaflaştırılmıştır.
